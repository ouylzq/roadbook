# toggle-done

## 它长什么样

每条任务最左边一个原生复选框，可访问名「切换 <标题>」。点它 → 标题加删除线，
header 计数器「未完成 N」减一。
到位：看 header 计数器或统计页的「已完成」，**不看复选框本身**。

## 变体

- 再点一次取消完成，计数器加回去。

## 已知会失败的方式

- 勾了却说不清勾上没 → `read_page` 的可访问树不带 checked 状态，`get_page_text` 更没有 →
  到位标志用 header 计数器或统计页文字（工具层，见 pitfalls §8）
- 连着勾两条，第二下点空 → 勾完整张列表重渲染，旧截图的坐标已经不对 →
  每勾一个等计数器变了、重新截图，再勾下一个
- 刷新后勾选没了 → 应用只渲染没写存储（`?bug=optimistic`）→ 到位标志在回读之后看
