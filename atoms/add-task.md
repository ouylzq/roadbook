# add-task

## 它长什么样

任务列表页顶部一行：左边输入框（placeholder「需要做什么？」），右边蓝色主按钮「添加任务」。
点输入框 → 输入标题 → 点「添加任务」。
到位：列表里出现该标题，header 计数器「未完成 N」加一。

## 变体

- 输入框里按 **Enter** 也能提交（它是原生 `<form>`）。按钮点不到时用。

## 已知会失败的方式

- 点了"输入框"却一个字都打不进去 → 点击落在了上方大标题上，输入框没获焦 →
  打字前先确认 placeholder 消失，或按文案搜「需要做什么？」取引用点
- 光标在、placeholder 消失、字就是进不去 → 视口被钉死时 `type` 静默失效 →
  打字步骤一律不钉视口（工具层，见 pitfalls §1）
- 加完立刻看列表和计数器都对，刷新就没了 → 应用只渲染、没写存储（`?bug=optimistic`）→
  到位标志在回读之后看，不在点完那一刻看
- 读页面文本读不到「未完成 N」 → 计数器在 header，不在主内容区 →
  用读页面结构取 header 区域
