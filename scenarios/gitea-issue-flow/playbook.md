# gitea-issue-flow 路书
> 最后勘路：2026-09-30

## 步骤

1. 【参考】—
   【目的】注册一个新用户
   【锚点】首页导航栏的「注册」链接
   【动作】点击「注册」进入 /user/sign_up，依次填写用户名、邮箱地址、密码、确认密码四个输入框，再点「注册帐号」按钮
   【到位标志】页面跳转回首页，出现文案「帐户创建成功。欢迎！」，导航栏从「注册/登录」变为「工单/合并请求/里程碑/探索/通知/创建…/个人信息和配置」，说明已自动登录为新用户
   注册成功后自动登录，不需要额外的登录步骤。填表时一个输入框一次动作：四个框塞进同一批的话，
   前一个动作会让后面几个的元素引用失效，那些调用会被整批跳过。

2. 【参考】—
   【目的】建出一个新仓库
   【锚点】导航栏「创建…」下拉菜单里的「创建仓库」菜单项
   【动作】点导航栏「创建…」菜单里的「创建仓库」，进入 /repo/create；填「仓库名称」输入框，勾选「初始化仓库（添加 .gitignore、许可证和自述文件）」复选框（不勾则仓库是空的，没有默认分支，后面开工单会更麻烦），再点「创建仓库」按钮
   【到位标志】跳转到 /<用户名>/<仓库名> 页面，看到「Initial commit」提交记录和 README.md 内容，说明仓库已真正建好且有初始分支
   不勾选初始化会创建空仓库，之后要走一遍 git 推送才有内容，勾选后 Gitea 自动生成 main 分支和一次 Initial commit，方便后续开工单

3. 【参考】—
   【目的】在仓库里开一个工单
   【锚点】仓库二级导航里的「工单」链接，工单列表页里的「创建工单」链接
   【动作】在仓库页点导航「工单」进入 issues 列表，再点「创建工单」进入 /issues/new；在「标题」输入框填工单标题，正文留空，点「创建工单」按钮
   【到位标志】跳转到 /<用户名>/<仓库名>/issues/1，标题显示为「<标题> #1」，状态显示「开启中」
   正文（描述）是可选的，不填也能创建，页面会显示「没有提供说明。」

4. 【参考】—
   【目的】在工单下发一条评论
   【锚点】工单详情页正文下方的评论表单，输入框旁边有「评论并关闭」和「评论」两个按钮
   【动作】在工单详情页底部的评论输入框（可访问名「留下评论」）里打字，再点独立的「评论」按钮（不是「评论并关闭」）
   【到位标志】页面 URL 出现 #issuecomment-N 锚点，顶部「由 xxx 于创建 · N 评论」计数增加，新评论正文以段落形式出现在页面文本里
   按钮有两个，「评论并关闭」会同时关掉工单，这一步只发评论要点纯「评论」那个；「评论」按钮在输入框为空时是 disabled 状态，打字后才可点

5. 【参考】—
   【目的】把工单关掉
   【锚点】工单详情页评论表单里的「关闭工单」按钮（工单开启中时显示这个文案，关闭后变成「重新打开」）
   【动作】在工单详情页的评论表单里点「关闭工单」按钮（不点评论输入框，直接点这个按钮即可，不需要先打字）
   【到位标志】页面顶部状态标签从「开启中」变为「已关闭」，正文区多出一条「于 关闭此工单」的时间线记录，评论表单按钮变为「重新打开」
   默认工单列表只显示开启中的工单，关闭后要用 ?state=all 才能在列表页看到它
