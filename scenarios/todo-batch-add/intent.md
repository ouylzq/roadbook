# 场景：批量添加（演示）

## 什么时候跑

用户说"多加几条""批量加""连续操作会不会丢"。它和 todo-persistence 是两个场景而不是一个场景带参数——值不同就另开目录。

## 目标

连着加三条任务，三条都真的被存下来，计数器和统计页对得上。

## 环境

```
preview_start { "name": "demo" }        # 在 http://localhost:4173 上跑 demo-app
```

## 固定参数

- 三条标题依次是 `批量演示 1`、`批量演示 2`、`批量演示 3`，别编别的。
- 场景假定从零开始：列表非空要先清空（见原子 `reset-demo-data`）。

## 留给裁判的事实

`runs/<本次>/context.yaml` 只写你实际输入的标题，按输入顺序：

```yaml
task_titles:
  - 批量演示 1
  - 批量演示 2
  - 批量演示 3
```

## 清理

清空演示数据。清理失败不改变结论，记录即可。

## 红线

没有，只碰 localStorage。
