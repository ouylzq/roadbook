# 场景：重置演示数据（演示）

## 什么时候跑

用户说"重置""清空""清理按钮对不对"。它同时也是其他场景清理手段的自检。

「重置演示数据」这个按钮是别的场景的清理手段，它自己也得是对的：点完存储要真空，不能只把列表画空。

## 目标

列表非空时点重置，刷新后列表、计数器、统计页全是零。

## 环境

```
preview_start { "name": "demo" }        # 在 http://localhost:4173 上跑 demo-app
```

## 造数

先加一条任务 `待清空`，让列表非空——否则重置无从验证。

## 留给裁判的事实

`runs/<本次>/context.yaml`：

```yaml
seeded_title: 待清空
```

裁判的路线不引用它，留着只是让这次 run 可追溯。

## 清理

不需要，场景本身就是清理。

## 红线

没有，只碰 localStorage。
