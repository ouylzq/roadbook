# 场景：标记完成（演示）

## 什么时候跑

用户说"勾选""标记完成""完成状态会不会丢"。

加两条任务，把第一条勾成已完成，确认"已完成"这个状态是存下来的，不只是画了条删除线。

## 目标

两条任务里一条已完成、一条未完成，刷新后仍然如此，统计页对得上。

## 环境

```
preview_start { "name": "demo" }        # 在 http://localhost:4173 上跑 demo-app
```

## 固定参数

- 两条标题依次是 `完成演示 1`、`完成演示 2`。
- 勾 **第一条**（`完成演示 1`）。
- 场景假定从零开始：列表非空要先清空（见原子 `reset-demo-data`）。

## 留给裁判的事实

`runs/<本次>/context.yaml`：

```yaml
task_titles:
  - 完成演示 1
  - 完成演示 2
done_title: 完成演示 1
```

## 清理

清空演示数据。清理失败不改变结论，记录即可。

## 红线

没有，只碰 localStorage。
