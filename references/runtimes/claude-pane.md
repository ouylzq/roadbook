# 运行时：Claude Code 桌面版浏览器 pane

在 Claude Code 桌面版里交互式跑时用的运行时。人能看见 pane，也能随时接管。

## 怎么认出是我

工具里有 `computer`、`read_page`、`get_page_text`、`navigate` 这一组（`mcp__Claude_Browser__*`）。

## 能力绑定

| 能力 | 工具 |
|---|---|
| 看画面 | `computer` action=screenshot |
| 按坐标点 | `computer` action=left_click，带坐标 |
| 读页面文本 | `get_page_text`（默认取 `<main>`） |
| 读页面结构 | `read_page`（`--filter interactive` 只要可交互元素） |
| 按引用点 | `computer` action=left_click，带元素引用 |
| 找元素 | `find` |
| 打字 | `computer` action=type |
| 写表单值 | `form_input` |
| 打开网址 | `navigate` |
| 跑只读脚本 | `javascript_tool` |
| 设视口 | `resize_window` |
| 管标签页 | `tabs_context` / `tabs_select` |
| 提议原子 | **没有记忆层**——直接编辑 atoms/<节点>.md 文件，自己守 atoms/README.md「谁能写」的规则：已有原子只追加、新原子直写、「它长什么样」不动 |
| 给候选投票 | 没有记忆层——没有候选可投 |

多个调用可以合进一个 `browser_batch` 省往返，但**打字不要和点击合批**（见下）。

## 这个运行时特有的坑

### 钉住视口会让打字失效

两种行为不能两头都要：

| 设置 | 像素坐标 | 打字 |
|---|---|---|
| `resize_window` 钉成固定尺寸 | 准——截图帧和视口一致 | **静默失效**：光标在、placeholder 消失了，但字进不去 |
| `resize_window preset=desktop`（不钉） | 截图被缩放，每次点击前必须用新截图重算坐标 | 正常 |

**规则：任何需要打字的步骤都必须在不钉视口的状态下跑。** 只有纯点击的步骤才可以钉。
这条排查花了四个错误假设才定位——表现看着像焦点 bug，完全不像视口 bug。

推论：不钉视口时**每次点击前立刻重新截图，只用那张图的坐标**。绝不跨截图复用坐标——
pane 可能在两次调用之间被改了尺寸，帧会重新缩放，手里的坐标全部静默失效。

把点击和打字放进同一个 `browser_batch` 也会让字进不去。不是节奏问题，分开调用一样失败，
别在这上面反复试——先查视口是不是被钉了。

### pane 被隐藏时页面根本不渲染

用户切走 pane 时页面停止渲染：

- `computer` 的滚动 / hover / 拖拽 / 截图 **直接超时**
- 隐藏期间加载的页面**没有排版**——`read_page` 报 0×0 视口，按 ref 点击落不到任何地方

还能用什么：

1. 隐藏时**按引用点、找元素、读页面结构、读页面文本仍然可用**。靠这几样能走完一整段流程——
   单选框、步进器、提交按钮都能按引用点，结果用页面文本验。这是硬边界允许的 DOM 退守，
   把原因写进 run 报告即可。
2. **隐藏期间不要刷新。** 必须刷新时先对同一 URL 调 `preview_start`——它会把 pane 拉回来并
   **新开一个 tab**。关掉旧 tab、在新 tab 上继续，tab id 变了，后续每个调用都要带新的。
3. 最省事的办法是让人把 pane 留在前台。

### 没有文件上传能力

这套工具里没有文件选择器。点「+」或「添加附件」只会唤起操作系统对话框，
pane 既看不到也驱动不了它——页面毫无变化，看起来就像按钮坏了。

绕法：用「跑只读脚本」这项能力在页面里构造 `File`（或 `DataTransfer`）派发给 `input[type=file]`，
然后读页面文本确认附件卡渲染出来了。**这是全套流程里唯一一处脚本操作页面属于必需而非退守的地方**，
用到的地方要在路书里明确说明。

### 读不到勾选状态

`read_page` 里 checkbox 只有名字（`checkbox "切换 xxx"`），**勾没勾看不出来**，页面文本更不会有。
所以"这条已完成"这种状态不能拿列表页当证据——要么去一个把状态写成文字的页面，
要么按裁判协议「表单控件的值怎么取证」用只读脚本读 `checked`，并在 `how` 里说明为什么文本层读不到。
